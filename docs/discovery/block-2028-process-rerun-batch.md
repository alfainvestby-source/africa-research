## What “process” means here (reminder)

- Entity = **development dossier**, not apartment listings.  
- Block CSV / WP pull = discovery seed only.  
- Unit beds/prices/payment only after ≥2 non-Block sources agree (or developer canonical).  
- Photo collector / geo enricher after dossier skeleton exists.  
- **Ready** unit ads / handed-over developments = mark only, **no dossier** ([portal-inventory-class-research-rules.md](portal-inventory-class-research-rules.md)). **Coming soon** = review in scope.
