## Source selection rule (locked)
1. **Scan ~10** candidate sources quickly  
2. **Keep ≥5** that carry the most usable fields for the effort  
3. **Always keep** developer / official project site (and official brochure/PDF / EIA filing) even if thin on price  
4. Skip thin stubs (search snippets, 500 pages, one-line aggregator cards) unless they are the only evidence for a conflict  
5. Record both `sources_evaluated` (approx) and `sources_retained` in the dossier
